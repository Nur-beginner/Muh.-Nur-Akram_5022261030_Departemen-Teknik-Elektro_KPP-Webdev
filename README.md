# ISMART Competition Website

## Nama Peserta
- Muh. Nur Akram
  
## Deskripsi Proyek
Website ISMART Competition merupakan website informasi perlombaan akademik tingkat SMP yang diselenggarakan oleh siswa SMA. Website ini dirancang untuk menyajikan informasi mengenai kategori lomba, jadwal kegiatan, dan informasi kompetisi dengan tampilan modern dan responsif.
